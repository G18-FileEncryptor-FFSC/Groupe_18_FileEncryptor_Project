# Guide d'utilisation

## 1. Présentation

FileEncryptor permet de chiffrer et de déchiffrer des fichiers localement à l'aide d'un secret ou d'un mot de passe.

L'application mobile Flutter constitue l'interface principale actuellement développée.

## 2. Chiffrement d'un fichier

Le processus de chiffrement prévu est le suivant :

1. Sélectionner un fichier.
2. Fournir le secret nécessaire au chiffrement.
3. Lancer l'opération de chiffrement.
4. Enregistrer le fichier chiffré.

Les détails de l'interface et les étapes exactes seront complétés lorsque la fonctionnalité sera implémentée et testée.

## 3. Déchiffrement d'un fichier

Le processus de déchiffrement prévu est le suivant :

1. Sélectionner un fichier chiffré.
2. Fournir le secret utilisé lors du chiffrement.
3. Lancer l'opération de déchiffrement.
4. Enregistrer le fichier déchiffré.

Les détails seront mis à jour lorsque la fonctionnalité sera disponible.

## 4. Historique

L'application prévoit une fonctionnalité permettant de consulter les opérations précédentes de chiffrement et de déchiffrement.

Cette partie sera documentée lorsque l'historique sera implémenté.

## 5. Paramètres

Une section dédiée aux paramètres est prévue dans l'application.

Son fonctionnement sera documenté lorsque les paramètres auront été définis et implémentés.

## 6. Gestion des erreurs

L'application doit informer l'utilisateur lorsqu'une opération ne peut pas être effectuée, par exemple lorsqu'un fichier est invalide ou qu'un secret incorrect est fourni.

Les messages et les cas d'erreur seront documentés en fonction du comportement réel de l'application.
