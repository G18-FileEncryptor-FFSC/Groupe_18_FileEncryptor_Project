# Guide d'installation

## 1. Présentation

Ce document explique comment préparer l'environnement nécessaire pour installer et exécuter FileEncryptor.

## 2. Prérequis

Les outils nécessaires au développement du projet sont notamment :

* Flutter
* Dart
* Git
* Un environnement de développement compatible avec Flutter, comme Visual Studio Code ou Android Studio.

## 3. Récupération du projet

Le projet peut être récupéré depuis son dépôt GitHub.

```bash
git clone <https://github.com/Dexquis-Jr/Groupe_18_FileEncryptor_Project.git>

```

Après le clonage, accéder au dossier du projet :

```bash
cd Groupe_18_FileEncryptor_Project
```

## 4. Installation des dépendances

Les commandes d'installation des dépendances seront ajoutées lorsque la structure technique du projet et ses dépendances auront été définies et testées par l'équipe.

## 5. Lancement de l'application

Les instructions permettant de lancer l'application mobile seront ajoutées lorsque la première version exécutable de l'application sera disponible.

## 6. Vérification

Avant de commencer le développement, vérifier que l'environnement Flutter et Dart fonctionne correctement.

Les commandes exactes utilisées par l'équipe seront documentées et testées avant leur ajout définitif à ce guide.
